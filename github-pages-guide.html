Free Hosting Guide

How to share HTML files as live URLs — for free, forever

This guide walks you through hosting HTML files on GitHub Pages so anyone can view them in a browser — no downloads, no account required to view, no expiry, no cost. Takes about 5 minutes from scratch.

1

Create a free GitHub account

Go to github.com and sign up. Choose a username — it will appear in every URL you share, so pick something clean (e.g. your name).

Note: The free GitHub plan is all you need. Don't upgrade anything.
2

Create a new repository

A repository is just a folder that lives on GitHub. Think of this one as your permanent home for all shareable HTML files.

  • Click the + icon in the top right → New repository
  • Name it something like shared-pages
  • Set visibility to Public
  • Turn on Add a README file — this is required
  • Leave everything else as default
  • Click Create repository
3

Upload your HTML file

  • From your new repo, click Add file → Upload files
  • Drag your HTML file in, or click to browse and select it
  • Scroll down and click Commit changes
Important: The filename becomes part of the URL, so name your file something clean before uploading — no spaces, use hyphens instead. Example: team-profile.html, not My Team Profile (final).html
4

Turn on GitHub Pages

This is the step that converts your repo into a live website.

  • Go to your repo and click Settings (top tab bar)
  • In the left sidebar, click Pages
  • Under Branch, change the dropdown from "None" to main
  • Leave the folder set to / (root)
  • Click Save
Wait about 60 seconds, then refresh the page. A banner will appear saying "Your site is live at https://yourusername.github.io/shared-pages/" — that confirms it worked.
5

Build your shareable URL

Your URL is always the same base pattern with the filename added to the end:

https://your-username.github.io/shared-pages/your-filename.html

For example, if your username is roberto-calamari and your file is allan-astrology-profile.html:

https://roberto-calamari.github.io/shared-pages/allan-astrology-profile.html

Paste that into any browser — it loads as a fully rendered web page with no login or download required.

6

Adding more files in the future

Every new HTML file you share follows the same pattern — no new repos, no new settings.

  • Go to your shared-pages repo on github.com
  • Click Add file → Upload files
  • Upload your new HTML file and commit
  • Your new URL is live within ~60 seconds
To update an existing file: GitHub's upload UI only adds new files — it won't overwrite an existing one. To edit a file that's already there, click on it in the repo, then click the pencil (edit) icon to make changes directly in the browser.
